Interpretation: history improves the tested forest relative to its forest baseline. RF with five 24-hour history features has slightly higher threshold accuracy than baseline logistic regression (70.17% versus 70.11%), but lower AUC and higher log loss. These results do not demonstrate an overall RF improvement.

All five forests selected minimum leaf size 50, feature subsampling sqrt, and unrestricted maximum depth. There are 200 trees per forest. Selection minimized row-weighted forward-CV log loss across eight predeclared settings. No setting or threshold was selected using final-test performance.

Files and extraction method

  • data/weekly_market_metadata_complete.csv: every observed market, with metadata and result availability.
  • recorded_market_results.csv: all 13,794 recorded binary settlements.
  • all_market_result_coverage.csv: result coverage and candidate membership for all 78,543 markets.
  • markets_without_recorded_results.csv: the 64,749 unknown-result records.
  • 00_all_market_results.ipynb: executed all-market audit and optional refresh.
  • 01_rf_data_preparation.ipynb, 02_rf_models.ipynb, 03_rf_validation.ipynb: executed modeling workflow.

The optional refresh follows the supplied R/PostgreSQL method: query the 78,543 observed slugs in 79 batches, LEFT JOIN markets/events/resolutions, preserve missing records, and apply no settlement-date restriction. It prompts for the course password locally and does not use the public trades API.

Limits on interpretation

Labels are conditional gross profitability, not verified net returns or insider status. Fees, opening inventory/cost basis and non-trading position changes remain incomplete. Recorded resolution does not establish actual historical result-publication time. Candidate selection is retrospective. This test period had already been inspected in the original study, so these comparisons remain exploratory reuse. Event-only bootstrap intervals do not capture repeated-wallet dependence across events.

Actual-data execution. No synthetic model results are reported. Source-file hashes, preprocessing audits, model choices and saved-model hashes are included in the package. Raw trade Parquets are not duplicated in the download; cached derived inputs and fitted models are included.
